Place custom font files here.

Recommended format:
- `.woff2`

Example file names:
- `DummyDisplay-Regular.woff2`
- `DummyDisplay-Bold.woff2`

There is a usage example in:
- `client/assets/fonts/example-fonts.css`

If you want to use the font globally, import that pattern into:
- `client/styles.css`

If you want to use the font only in one scene, copy the `@font-face` block into that scene stylesheet and adjust the relative path.
